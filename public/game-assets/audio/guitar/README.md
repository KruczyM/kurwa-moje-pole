# Podkłady muzyczne do gitary przy ognisku (Guitarless Backing Tracks)

Tutaj należy umieścić pliki audio w formacie MP3 lub OGG (podkłady muzyczne z wyciętą lub wyciszoną samą gitarą prowadzącą).

Gra automatycznie wykryje te pliki i odtworzy je jako profesjonalny podkład, na który gracz nakłada na żywo partię gitary za pomocą klawiszy `[A, S, D, F, G]`.
